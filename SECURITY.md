# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `vector-classifier`, please do **not** open a public issue.

Instead, report it responsibly via:

- **Email:** Send details to **<ganssauge@gorki120.de>**
- **GitHub Security Advisory:** Submit a private vulnerability report via the **Security** tab of this repository.

### What to Include in Your Report

- Description of the vulnerability and its potential impact
- Detailed steps to reproduce or a minimal proof-of-concept
- Any relevant logs, configurations, or environment information

### Response Timeline

- **Acknowledgment:** Within 48 hours.
- **Assessment & Fix:** We will evaluate the report and work on a patch as promptly as possible.
- **Disclosure:** We will coordinate public disclosure after a fix has been released.
